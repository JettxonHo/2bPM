# 设计文档：2bPM 前端迁移 — Sphinx → VitePress

**日期**：2026-07-24
**状态**：待用户审阅
**作者**：Claude（与蔡舒起协作）

---

## 1. 背景与问题

《自学成 AI 产品经理》是一本用 Sphinx / d2lbook2 构建的在线书，296 个 markdown、约 240 万字，部署在 GitHub Pages（`https://stevenjokess.github.io/2bPM/`）。

**核心问题**：全站超链接是纯黄色 `#FFFF00`，白底对比度仅约 1.07（WCAG 可读标准要求 ≥4.5），刺眼且几乎不可读。

**根源**：主题为 `mxtheme`，配置项 `accent_color: 'yellow'`（位于自动生成的 `_build/rst/conf.py`），MDL 的"红-黄"配色将所有链接设为了强调色黄。

**用户诉求演进**：从"修复黄字" → 评估"是否该用主流技术栈" → 确认迁移到 VitePress，追求极简、类苹果官网、护眼的阅读体验。

## 2. 目标

| 目标 | 说明 |
|---|---|
| 解决可读性 | 链接对比度 ≥ 4.5，正文护眼，告别黄字 |
| 现代化体验 | 深色模式、全文搜索、响应式移动端、章节导航 + 页内大纲 |
| 极简观感 | 类苹果官网的干净排版，适合中文长文阅读 |
| 可维护 | 导航自动生成、内容源单一、构建部署自动化 |
| 平滑过渡 | 外部旧链接不失效，内容无丢失 |

**非目标**：不改动书籍正文内容本身；不引入评论、统计等新功能（YAGNI）。

## 3. 技术选型

- **框架**：VitePress v1.6（Vue 系静态站点生成器）。原型已验证可行。
- **内容源**：保留现有 `.md` 文件为唯一事实源；呈现层迁移，内容不动。
- **数学公式**：`markdown-it-mathjax3`（原型已装并验证）。
- **部署**：GitHub Pages，GitHub Actions 自动构建，产物输出沿用 `docs/`。
- **搜索**：VitePress 内置 local search（已验证中文可用）。

## 4. 已确认的关键决策

| 决策点 | 结论 |
|---|---|
| 迁移方向 | 全面迁移到 VitePress（非 CSS 覆盖现有站） |
| 章节 URL | **重命名为简洁 slug**（如 `ai-finance`、`ai-company`），**同时生成旧路径跳转页**，保证外部旧链接不失效 |
| 视觉基调 | VitePress 默认极简主题为基底，叠加用户选定的"折中"风格调性（暖白底 + 深灰正文 + 护眼链接色） |

## 5. 内容盘点与转换策略

**内容规模**：16 个章节目录、296 个 md、约 240 万字、443 处图片引用。

迁移写一个**一次性脚本 `scripts/migrate.mjs`**，对内容做非破坏性转换（原文件保持不动，转换在生成副本上进行）：

| 源格式 | 现状规模 | 转换方式 |
|---|---|---|
| 根 `index.md` 的 ` ```toc ` 块 | 定义 14 个章节顺序 | 解析 → 生成顶层导航 |
| 各章节 `index.md` 的 ` ```toc ` 块 | 每章一个，含文件清单 | 解析 → 生成该章 sidebar |
| `:label:` 锚点标记 | 26 处 | 删除（VitePress 以文件路径为锚） |
| 图片路径 `/img/`、`img/`、`./img/` | 443 处，三种混用 | 统一规范化；图片集中到 `public/img` |
| `get_started.md`、`AI_critical.md` 的 git 冲突标记 | 2 个文件（遗留 bug） | **人工先解决合并冲突**，再迁移 |
| 数学公式 `$$` | 2 个文件 | mathjax3 直接渲染 |
| 标准脚注 `[^x]` | 34 个文件 | 原生支持，无需处理 |

## 6. 目标项目结构

```
2bPM/
├── chapters/                  # 各章节 md（重命名为简洁 slug 目录）
├── *.md                       # 根级页面（index、get_started、AI_critical…）
├── img/                       # 图片源
├── site/                      # VitePress 站点（新）
│   ├── .vitepress/
│   │   ├── config.mts         # 站点配置
│   │   ├── sidebar.ts         # 脚本生成的导航（构建期产物）
│   │   ├── redirects.ts       # 旧路径 → 新路径 映射
│   │   └── theme/             # 自定义主题（折中风格 custom.css）
│   └── public/img/            # 统一后的图片
├── scripts/
│   └── migrate.mjs            # 一次性迁移脚本（转换 + 生成导航 + 生成跳转）
├── .github/workflows/
│   └── deploy.yml             # 自动构建并发布到 GitHub Pages
└── docs/                      # 构建产物（部署目标，沿用现有）
```

> 旧 Sphinx 产物（现有 `docs/` 内容、`_build/`）在迁移验证无误后另行清理，不在本次范围。

## 7. 章节 slug 命名映射（示例）

| 原目录 | 新 slug |
|---|---|
| `chapter_introduction` | `introduction` |
| `chapter_idea` | `idea` |
| `chapter_knowledge` | `knowledge` |
| `chapter_AI+Finance` | `ai-finance` |
| `chapter_AI_company` | `ai-company` |
| …（其余同理，去 `chapter_` 前缀、`+` 转 `-`、小写化） | |

旧路径 `chapter_AI+Finance/FinTech.html` → 跳转 → 新路径 `ai-finance/FinTech`。

## 8. 视觉设计（折中风格）

浅色模式基于 VitePress 默认主题微调：

- 背景：暖白（`#fafaf7` 方向）
- 正文：深灰近黑（高对比、护眼）
- 链接：护眼深色（对比度 ≥ 4.5，告别黄色）
- 中文排版：行距、字号、段间距优化，适合长文阅读

深色模式使用 VitePress 自带（无需额外工作）。

## 9. 验证方式

1. **完整性**：迁移脚本输出清单，确保 296 个源文件全部有对应生成页，无遗漏。
2. **浏览器实测**：浅色/深色模式切换、全文搜索、图片渲染、公式渲染、脚注、跨章节链接、旧链接跳转。
3. **抽样比对**：老站与新站同章节内容一致。
4. **构建通过**：`vitepress build` 无错误。

## 10. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 2 个文件的 git 冲突标记阻塞迁移 | 迁移脚本前置：先人工解决冲突（顺带修复遗留 bug） |
| 图片路径混乱导致个别图片 404 | 迁移后跑链接检查，浏览器抽样验证 |
| 旧链接跳转覆盖不全 | 跳转映射由脚本从源目录结构自动生成，覆盖全部旧路径 |
| 内容转换破坏原文件 | 转换只作用于生成副本，原 `.md` 不动，可随时回退 |

## 11. 实施步骤概要

1. 解决 `get_started.md`、`AI_critical.md` 的 git 合并冲突
2. 编写 `scripts/migrate.mjs`（转换 + 生成导航 + 生成跳转）
3. 重命名章节目录为 slug，运行迁移脚本
4. 配置 VitePress 站点 + 折中风格自定义 CSS
5. 浏览器全面验证（含深色模式、搜索、跳转）
6. 配置 GitHub Actions 自动部署
7. 部署上线，确认旧链接跳转生效
